This is a simple, locally run app that analyzes and compares apps using the Google Play Store dataset to gain insights into the app and its market performance.

Follow these steps:

Create the venv using requirements.txt
for the data: it needs two csv files from
https://www.kaggle.com/datasets/lava18/google-play-store-apps 
upload the two files googleplaystore.csv and googleplaystore_user_reviews.csv to same working directory as app.py

credits to: https://www.kaggle.com/datasets/lava18/google-play-store-apps
